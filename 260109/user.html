        - "{"name" : "홍길동", "age" : "20"}"           ->  객체, ex) 파이썬에서 딕셔너리
        - [100,200,300] or ["apple","banana","mango"]   ->  배열

        - json은 문자열이며 객체형태를 가지고 있음 -> "{\"name\" : \"홍길동\", \"age\" : \"20\"}"
        - json을 객체로 변경하는 함수 JSON.parse(json문자열);
        - 네트워크에서 데이터를 전송하기 위해서는 객체를 전송할 수 없음
